# Winter Calendar 2026

An interactive advent calendar web app. Static site (GitHub Pages,
Vite + TypeScript), personal content encrypted client-side
(AES-GCM), unlocked once per device with a name + password pair.
Single intended user.

## Phases
- P1 Foundation: trinity, CI, PWA shell, door grid (WC-01)
- P2 Privacy: password gate + crypto, encoder tool (WC-02, WC-03)
- P3 Calendar: door logic, unlock, lightbox, deployment (WC-04)
- P4 Delight: living-room scene, scratch-off, door-24 mini-game
  (WC-05, WC-06, WC-07)

## Status
- WC-01 Bootstrap & Calendar Grid: implemented (PR #1)
- WC-02 Password Gate & Content Encryption: implemented (PR #2)
- WC-03 Local Content Encoder: in progress
